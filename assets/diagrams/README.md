# assets/diagrams

Fuentes de diagramas editables para material visual de presentación.

## Objetivo

Mantener versiones fuente (no render final) de diagramas conceptuales para facilitar revisiones sin exponer información sensible.

## Convenciones

- Formato preferido: Mermaid (`.mmd`) y/o Markdown con bloques Mermaid.
- Nombres descriptivos en `snake_case`.
- Diagramas sin datos reales, sin PII y sin referencias privadas.
