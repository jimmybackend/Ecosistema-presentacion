# Assets

Repositorio de material visual público para presentación comercial/técnica.

## Reglas de publicación

- Solo imágenes y diagramas **públicos y aprobados** para difusión.
- Prohibido incluir credenciales, tokens, claves API o secretos.
- Prohibido subir capturas con PII (datos personales identificables).
- Prohibido incluir URLs privadas, endpoints internos o rutas administrativas.
- Prohibido publicar datos de clientes, contratos o reportes sensibles.

## Alcance actual

- Diagramas base en texto/Mermaid para demo segura.
- Material preparado para evolucionar a PDF o GitHub Pages en una fase posterior.

## Estructura sugerida

- `assets/diagrams/`: fuentes editables de diagramas (`.mmd`, `.drawio`, etc.).
- `assets/img/`: imágenes públicas genéricas sin datos reales.

Ver también: [`docs/diagramas.md`](../docs/diagramas.md).
