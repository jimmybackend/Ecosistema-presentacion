# Glosario

## Tenant

Organización, cliente o unidad que usa el sistema de forma separada.

## Feature flag

Interruptor de configuración que permite activar o desactivar capacidades de forma controlada.

## Read-only

Modo de sólo lectura. No modifica datos.

## Dry-run

Simulación segura de una acción. Muestra qué ocurriría sin ejecutar cambios.

## Controlled

Modo de ejecución real, pero protegido por flags, permisos y validaciones.

## Submission

Envío de formulario desde una landing page.

## Lead

Contacto u oportunidad comercial dentro del CRM.

## Workflow

Regla de automatización que responde a eventos del sistema.

## Knowledge pack

Paquete de conocimiento usado por IA para responder o proponer acciones.

## Go-live

Proceso de preparación para lanzar el sistema a uso real.
